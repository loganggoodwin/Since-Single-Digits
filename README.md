# Since Single Digits

**A tribute song for Nathan Legasse**  
**From:** Garth

![Since Single Digits Cover](assets/since-single-digits-cover.png)

## About This Project

**Since Single Digits** is a heartfelt tribute song dedicated to **Nathan Legasse**, my best friend and only friend in the whole wide world.

We met when we were kids growing up in the **Elmwood projects**, and we have been best friends ever since we were in the single-digit years of life. This project is about loyalty, brotherhood, memory, and the kind of friendship that stays strong through every stage of life.

This repository includes the finished song files, cover art, and video file so the project can be saved, shared, and uploaded as a complete tribute package.

## Project Files

## Song Theme

This song is about:

- Gratitude for a friend who has always been there
